
# Traduire l'application
La contribution des traductions à l'application Meshtastic Apple permet de rendre le projet accessible à un public plus large. L'application utilise [catalogues de chaînes](https://developer.apple.com/documentation/xcode/localizing-and-varying-text-with-a-string-catalog) dans Xcode pour gérer les traductions.
## Traduction automatique de la documentation
Sur les appareils fonctionnant sous iOS 26 ou version ultérieure, la documentation intégrée à l'app est automatiquement traduite dans la langue de votre appareil lorsque vous ouvrez la section **Aide et documents**. Le pipeline de traduction fonctionne comme suit :
1. L'application lit les fichiers sources de démarquement anglais groupés.2. Les segments de texte sont traduits à l'aide du cadre de traduction d'Apple. Si le cadre de traduction ne prend pas en charge votre langue, l'application revient à FoundationModels sur l'appareil.3. La démarque traduite est mise en cache localement afin que les visites suivantes se chargent instantanément.4. La démarque traduite est convertie en HTML sur l'appareil et affichée dans la visionneuse de documents.
Une fois que toutes les pages de documentation ont été traduites en arrière-plan, l'application télécharge automatiquement les fichiers de démarque traduits dans le référentiel [meshtastic/translations](https://github.com/meshtastic/translations). Cela permet à la communauté d'examiner et d'améliorer les traductions générées par machine.
> **Conseil - Utilisateurs anglais** Si la langue de votre appareil est l'anglais, aucune traduction ne se produit et la documentation anglaise fournie est affichée directement.
## Comment contribuer aux traductions de l'interface utilisateur
Si vous souhaitez mettre à jour les traductions d'une région existante ou ajouter une nouvelle langue, procédez comme suit :
1. Fourchez le [dépôtiment Meshtastic-Apple](https://github.com/meshtastic/Meshtastic-Apple/tree/main) vers votre compte GitHub.2. Clonez le projet et ouvrez `Meshtastic.xcworkspace` dans Xcode.3. Sélectionnez le fichier `Localizable.xcstrings` dans le navigateur de projet.4. Suivez les [étapes pour ajouter ou mettre à jour des traductions](https://developer.apple.com/documentation/xcode/localizing-and-varying-text-with-a-string-catalog) dans la documentation d'Apple.5. Créez une demande de tirage sur le projet avec vos modifications.
Votre contribution sera examinée et, après approbation, votre traduction sera incluse dans la prochaine version de l'application Meshtastic Apple.
> **Conseil - Nouvelle langue ? ** Si vous ajoutez une langue qui n'est pas encore présente dans le projet, ouvrez les paramètres du projet Xcode, allez dans **Info → Localisations** et ajoutez la nouvelle langue avant de modifier `Localizable.xcstrings`.
Merci d'avoir aidé à élargir la portée de Meshtastic !
